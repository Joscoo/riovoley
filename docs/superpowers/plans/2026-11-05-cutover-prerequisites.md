# Prerrequisitos operativos sin tareas de claves

Objetivo: comprobar la disponibilidad de puntos de recuperación administrados y precisar las condiciones de corte pendientes, sin habilitar mantenimiento ni modificar producción.

1. Abrir un expediente nuevo; conservar intactos los expedientes sellados.
2. Consultar `supabase backups list` para el proyecto institucional con la sesión CLI existente. Conservar códigos, tiempos y campos permitidos; no publicar diagnósticos de autenticación.
3. Contrastar plan y documentación oficial mediante MCP; no contratar servicios ni suponer capacidad por el nombre del plan.
4. Revalidar únicamente el ciphertext existente y referencias estáticas de los canales de acceso. No descifrar ni renovar respaldos.
5. Documentar criterios de inicio, aborto y retorno, indicando qué falta comprobar. No presentar una página web ni un marcador SQL como bloqueo efectivo.
6. Generar los tres documentos académicos, verificar cifras, referencias, privacidad y manifiestos previos; sellar y subir exclusivamente estos avances a la rama autorizada.

No se repiten pruebas funcionales ni compilaciones porque esta fase no modifica el producto. Sus antecedentes conservan denominadores, fuentes y fechas. La preparación no concede autorización de despliegue, SQL o cambios de permisos.
