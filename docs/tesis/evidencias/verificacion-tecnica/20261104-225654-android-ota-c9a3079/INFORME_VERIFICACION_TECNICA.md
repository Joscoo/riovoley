## Seguridad, incidencias y límites

El escaneo descomprimió los miembros ZIP y comparó valores institucionales conocidos, clave server y contraseñas locales prohibidas, además de patrones JWT. Solo se toleraron los inputs anon/PII del cliente local dentro del APK privado. El resultado no certifica ausencia universal de secretos. Los informes y logs públicos pasan una revisión independiente del contenido del APK; no contienen valores ni digests de credenciales. [Privacidad APK](seguridad/privacidad-apk-local.json), [privacidad del expediente](PRIVACIDAD.json).

Se conservan dos fallos del comprobador estático, con códigos 1: exigía que no existiera el literal del panel en el bundle. Esa expectativa era más fuerte que el requisito de interfaz. Con una variable CRA omitida, el código protegido puede conservarse como texto, aunque el valor distinto de true impida renderizarlo. Se corrigió el comprobador para registrar ese texto (1 archivo), manteniendo la prueba funcional nativa de ausencia del control. No se cambió App ni se modificaron expectativas de roles/recompensa para conseguir aprobación. [Primer intento](android/privacidad-y-contenido.meta.json), [diagnóstico](android/privacidad-diagnostico.meta.json), [cierre](android/privacidad-cierre.meta.json), [vinculación](android/fuentes-y-artefacto.json).

Tras la pausa, Docker estaba detenido y se reanudó localmente. La memoria libre fue insuficiente al principio; no se inició el AVD hasta que el usuario liberó recursos. Gradle advirtió sobre flatDir, deprecaciones incompatibles con Gradle9 y avisos Kotlin del plugin Filesystem; React/Node emitió DEP0176. Estos avisos no se ocultan ni se corrigieron editando dependencias instaladas. [Logs de Gradle](android/gradle.stdout.log), [stderr web](compilacion-web/web-build.stderr.log), [reanudación](android/reanudacion-entorno.json).

No se ejecutaron Jest completo, suites Playwright de escritorio, FCM, Resend, descarga/instalación OTA, recuperación real con token ni auditoría de RLS institucional en esta fase. El [Jest anterior de 426 casos](../20261104-223055-ota-diagnostico-0d0d488/INFORME_VERIFICACION_TECNICA.md) corresponde al mismo App de la base, pero no se atribuye como nueva ejecución. Este APK debug tampoco reemplaza la validación de un release firmado con el cambio.
