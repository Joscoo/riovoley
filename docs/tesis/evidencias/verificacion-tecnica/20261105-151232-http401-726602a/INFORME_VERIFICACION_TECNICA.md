## Resultado del diagnóstico

Se registraron 298 respuestas locales y 0 errores HTTP. El flujo instrumentado no reprodujo errores HTTP. No permite determinar la causa de los dos 401 históricos; la incidencia conserva ese límite y no se declara corregida.

Los datos exactos incluyen phaseAtStart y phaseAtResponse, comparación booleana con anon local, presencia de sub, errorCode y lectura de cabeceras completas para los errores. No se guardan valores originales. [ANALISIS_HTTP401.json](ANALISIS_HTTP401.json) conserva las filas clasificadas. Las dos respuestas del expediente anterior carecían de esa instrumentación: no se les atribuye retrospectivamente una fase o token concreto.

Una prueba controlada adicional en Chromium de escritorio, con el mismo cliente compilado y servicios locales reales, retuvo la entrega de respuestas GET de anuncios ya obtenidas del servidor hasta completar logout y comprobar ausencia de token local. Al liberar las respuestas sin alterar su contenido, la carga de notificaciones continuó con 2 GET de logros, enviados como anon local sin sub y rechazados con HTTP401/42501. Esto reproduce un mecanismo causal de continuación tardía después del cierre; no es otra ejecución Android ni datos de backend simulados.
