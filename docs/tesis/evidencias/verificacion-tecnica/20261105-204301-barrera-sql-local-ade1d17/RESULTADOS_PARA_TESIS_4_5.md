# Propuesta para revisión académica del apartado 4.5

Como verificación complementaria, se ensayó una barrera de escritura SQL en una base PostgreSQL 17.11 separada, formada por siete relaciones sintéticas y sin registros institucionales. El control previo permitió la inserción desde cinco actores de base de datos; posteriormente, la suite final aprobó 47 de 47 casos, sin fallos ni omisiones, utilizando conexiones reales y sin repositorios simulados ([control previo](integracion/baseline.stdout.log), [resultados finales](integracion/green-final.stdout.log)). Los casos comprobaron rechazo específico de operaciones de escritura, llamadas a una RPC sintética SECURITY DEFINER, acceso mediante vista y particiones, sesiones anteriores al cierre y rollback de cambios parciales ante conflictos de bloqueo. La retirada del prototipo restituyó las escrituras de los cinco actores y conservó los snapshots de las fixtures ([estado posterior](integracion/estado-final-laboratorio.json)).

Se conservó también una ejecución previa de rechazo que falló en ausencia de la barrera, así como una primera ejecución satisfactoria de 44 casos; estos antecedentes no se sumaron al denominador final ([fase RED](integracion/red.stdout.log), [primer ensayo](integracion/green.stdout.log)). El resultado corresponde a integración SQL local y no acredita recuperación o autenticación mediante APIs gestionadas, modificación de objetos Storage, entrega de notificaciones ni aislamiento completo de producción. En esta fase no se repitieron pruebas Jest, Playwright o compilaciones web/Android, cuyos resultados anteriores mantienen su identificación en el [expediente funcional](../20261105-152944-notifications-cancel-e903a31/INFORME_VERIFICACION_TECNICA.md). La aplicación institucional de un mecanismo de mantenimiento continúa pendiente de cobertura completa, revisión del paquete y condiciones operativas documentadas ([alcance y límites](PROPUESTA_AISLAMIENTO_SQL.md)). Estas pruebas no aportan resultados de usabilidad, motivación o capacidad de interacción.
